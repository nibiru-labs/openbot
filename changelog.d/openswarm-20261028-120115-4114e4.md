### Fixed

- The marker of a finished hosted site change no longer retries every second. Before, a database
  that could not take the marker made OpenBot write to it every second for the rest of the session,
  and every attempt reported an error. Now the number of tries is small, the wait between them
  grows, the failure is reported once, and the marker is written the next time OpenBot starts.
- A failed tool search now names its cause. Before, a broken database, a failed provider and a
  malformed request all reached the agent as "the tool request is invalid", and the cause was
  nowhere. Now the cause is reported as well, and the agent still gets the same sentence.
- A failed read of the token count is now reported. Before, a database that could not be read left
  the hourly token limit at zero and said nothing, so the pause that protects your quota came late.
  Now the failure is reported, and the next usage report reads the count again, so the limit holds
  the tokens the database kept.
