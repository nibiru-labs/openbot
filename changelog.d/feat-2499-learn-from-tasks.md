### Added

- An agent can now learn from its completed tasks. Turn on "Learn from completed tasks" in the
  agent settings, and the agent saves durable lessons — a preference, a project convention, or a
  failure it fixed and verified — to its own memories at the end of a task that ends well. The
  setting is off unless you turn it on, and it is per agent. Saved lessons appear with the other
  memory changes of the task, and you can inspect, edit or delete them in the agent's memories.
