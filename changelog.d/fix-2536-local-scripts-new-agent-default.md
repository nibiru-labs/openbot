### Added

- A new app setting in Settings → Permissions, "Allow Local scripts for new agents". When it is
  on, an agent created on this computer — new, from a template, from the marketplace or by
  import — starts with Local scripts on, so a local integration reaches it at once. The setting
  is off by default, existing agents do not change, a copy keeps the setting of the agent it
  copies, and each agent keeps its own Local scripts switch.
