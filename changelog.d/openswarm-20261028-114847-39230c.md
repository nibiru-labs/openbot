### Added

- An end-to-end check of the media attachments and their size limits. It holds that an MP3 and a
  MOV file are stored unchanged with the MIME type of their own kind, that a file of 100 MB is
  stored and a file of one byte more is refused, that a message of 250 MB is refused, that ten files
  are stored and an eleventh file is refused, and that a remote host without the
  `media-attachments` capability refuses a recording.
